# 📋 Bitácora de Desarrollo
**Módulo:** ERP / Catálogos y Presupuesto
**Fase:** Optimización, Seguridad y Reportes (MVP)

## Avances Técnicos Implementados

1. **Validaciones Dinámicas de UI (Presupuesto):**
   - Se implementó lógica en Vanilla JavaScript para controlar dinámicamente el formulario de proyecciones. 
   - El sistema ahora restringe fechas futuras para el PIA y bloquea el año en curso al seleccionar "Año Vigente", ocultando o mostrando los meses de corte según corresponda.

2. **Motor de Exportación de Reportes:**
   - Se desarrollaron tres endpoints nativos en Go para la exportación en memoria (streaming) de la matriz de presupuesto.
   - **CSV:** Implementado con el paquete nativo `encoding/csv`.
   - **Excel:** Implementado con la librería `excelize/v2`, generando celdas dinámicas.
   - **PDF:** Implementado con `gofpdf`, utilizando formato apaisado (Landscape) y configurado para admitir la carga de logotipos estáticos de las entidades.

3. **Manejo Seguro de Nulos (Base de Datos):**
   - Se refactorizó la lectura de datos en el repositorio de Parámetros Globales.
   - Se implementó el uso del tipo nativo `sql.NullString` para proteger el sistema de caídas (panics) o pérdida de listas de datos cuando PostgreSQL devuelve valores nulos (específicamente en columnas como `descripcion` o `fecha_hasta`).

4. **Middleware de Seguridad Basado en Roles:**
   - Se desarrolló e inyectó el middleware `RequireRole` en el enrutador (`routes.go`).
   - Se corrigió la vulnerabilidad de acceso, garantizando que el panel de administración (`/admin`) exija estrictamente el rol `"super_admin"`, bloqueando accesos no autorizados con un estado HTTP 403 (Forbidden).

5. **Búsqueda Reactiva (HTMX) en Catálogos:**
   - Se implementó el patrón de Búsqueda Activa en los módulos de Inquilinos, Usuarios y Fuentes.
   - Se combinaron inputs de búsqueda con eventos temporizados de HTMX (`delay:500ms`) y consultas de coincidencia parcial (`ILIKE`) en PostgreSQL, actualizando únicamente el cuerpo de las tablas.

6. **Paginación Matemática y Filtros Combinados (MEF):**
   - Se integró un sistema de paginación mediante las cláusulas `LIMIT` y `OFFSET`.
   - Se modificó el repositorio para ejecutar un `COUNT(*)` previo, permitiendo calcular en el controlador de Go el número total de páginas (`math.Ceil`).
   - Se combinaron filtros de texto y selectores (Ingreso/Gasto, Año) agrupándolos en un formulario capturado con la etiqueta `hx-include` y navegando con `hx-vals`.

7. **Optimización de Renderizado (Go Templates):**
   - Se solucionó un bug visual de renderizado anidado (bucle infinito) en la interfaz de Conceptos Maestros.
   - Se diferenció estratégicamente el uso de `tmpl.Execute()` para cargas iniciales completas y `tmpl.ExecuteTemplate()` para respuestas parciales (quirúrgicas) demandadas por HTMX.
