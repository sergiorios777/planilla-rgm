Creación de Importador para contratos

1. Tabla contratos:

contratos

2. Plantilla de importación excel:
   - Se crea y entrega la plantilla al usuario, con la estructura de los datos requeridos, y una hoja con instrucciones detalladas.

3. Precisiones:
   - La identificación del trabajador se hace mediante su DNI o documento de identidad.
   - La identificación del puesto se hace necesariamente utilizando el código airhsp del puesto, para comodidad del trabajo del usuario se agrega una columna para el nombre del puesto en la plantilla de excel, pero que no será utilizada al procesar.
   - Si hay fallas en identificar a los trabajadores o al puesto se pasa al siguiente, pero se informa detalladamente al usuario de las fallas (¿es este enfoque adecuado?).
   - Utilizamos un worker pool para prevenir el procesamiento cantidades masivas de contratos.
   - Debemos asegurar que durante la imoprtación se ejecute la asignación de los conceptos tenant por cada puesto (contratos_servicios).
