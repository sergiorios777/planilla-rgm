Haz clic y selecciona la carpeta de donde quieres leer los archivos .md.

Bienvenido al Lector de Markdown

Dado que los navegadores web no pueden escanear el sistema de archivos automáticamente por seguridad, tienes dos opciones:

Método 1: Dinámico (Recomendado)

Haz clic en el botón azul "📂 Cargar Carpeta Local" del panel izquierdo y selecciona la carpeta docs. Esto permitirá listar al instante todos los archivos .md de forma jerárquica para leerlos.

Método 2: Servidor Web Estático

Si este archivo se sirve desde un servidor como Apache, Nginx o LiveServer y quieres que los archivos aparezcan pre-cargados, puedes editar el array estático en el código fuente (línea ~180 en el index.html) para mapear tus rutas manualmente.
